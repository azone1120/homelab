# Homelab Project
This is my personal homelab setup, built to explore and learn about system adinistration, virtualization, containerization, and networking on a budget. The idea strated with some spare parts and wanting to ruun my own data center. 

This project is still a work-in-progress, and I'm continuously tweaking it for better performance and power usage. 

## Hardware
### Dell Precision Tower 3620 - Specs:
- **CPU:** Intel Xeon E3
- **RAM:** 24GB DDR4
- **Storage:** SAMSUNG 870 EVO SATA 1TB
- **GPU:** NVIDIA Quadro K620
- **Motherboard:** OEM Dell LGA 1151 board
- **Power Supply:** Stock Dell PSU
- **Cooling:** Stock air cooling
